# Input data provenance

The `raw/` directory includes the **de-identified, processed public files used in the submitted manuscript reanalysis**. These are original third-party GEO and PhaSePro resources, NOT new data generated by this repository. Please credit and observe the access terms of the individual original datasets. Inclusion is for analysis reproducibility; a locally stored copy is not an official mirror of GEO.

| GEO series | Processed data file | Source page |
|---|---|---|
| GSE161537 | `GSE161537_nivobio_log2cpm.csv.gz` | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE161537 |
| GSE126044 | `GSE126044_counts.txt.gz` | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE126044 |
| GSE190265 | `GSE190265_TPM_France3.csv.gz`, `GSE190265_samples_info_France3.csv.gz` | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE190265 |

| GSE135222 | `GSE135222_GEO_RNA-seq_omicslab_exp.tsv.gz` | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE135222 |

PhaSePro source records are in `raw/download_full.json`; a curated list with provenance is under `gene_sets/` (original PhaSePro reference: https://doi.org/10.1093/nar/gkz848).

`clinical_extraction/` contains derived tables from GEO source metadata and is labeled as originally extracted, not independently clinical-record validated. Source metadata and raw matrix are non-identifiable public resources; nevertheless, publication of any derived patient-level table remains subject to original source terms.

## Known data restrictions

- GSE161537 targeted assay captures only 22 of the 59 curated PhaSePro genes.
- GSE190265 has 43 supplementary expression/PFS records, but only 26 exact GEO-title links among the 34 GEO accessions; analysis distinguishes linked and unlinked subsets.
- GSE190266 processed matrix has 16,383 gene columns and terminates alphabetically at `MTMR14`, compatible with an export truncation; this should not be read as biological absence of unmeasured genes.
- GSE135222 has 27 expression profiles with Ensembl IDs; no independently validated symbol mapping was used for gene-level analyses.
- GSE126044 has only 16 response-labeled cases and uses nonidentical response annotation relative to GSE161537.
