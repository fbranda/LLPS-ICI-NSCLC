# Curated candidate genes

`PhaSePro_human.txt` contains 59 curated human gene symbols used as the study's hypothesis set. Provenance and exclusion audit are retained as CSV files. **This set is not an exhaustive LLPS interactome.** A gene's presence is not direct evidence of measured condensate activity in NSCLC samples.

`MLORS_reference_six_genes.txt` documents the published six-gene signature components as reference only. **The published MLORS predictor and its original coefficients were not externally validated by the present analysis**, because not all components were measured on the development assay.
